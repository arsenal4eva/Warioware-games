# Warioware-games
My project to learn to use Godot in game dev
Part of a YSWS program on hackclub.com
First project using Godot.
Player has 5 lives to complete 3 minigames, a platformer, a clicker and a harder obstacle avoider.
Controls: left/right arrows for movement, spacebar for jump
Level 1:
Try to collect all the stars before time runs out
Level 2:
Click at least 4 stars before time runs out
Level 3:
Try not to get pushed into the spikes by the bullet bill for 30s

#Run it locally
1. Download the .zip file from this repo
2. Unzip the files into a normal folder.
3. Do not double-click index.html (Modern browsers block this for security, resulting in a black screen.)
4. Run a Local Server.
     Open a terminal in the folder and run python -m http.server (for Godot 3) or use the header script from earlier (for Godot 4).
